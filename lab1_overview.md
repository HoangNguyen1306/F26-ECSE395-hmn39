## Purpose of this Assignment

The purpose of **Lab 1** is to get comfortable with two essential tools used throughout
the semester:

1. **Markdown** — a lightweight markup language for creating formatted documentation
   using plain text syntax.
2. **GitHub** — a version-control platform used to store, manage, and share code and
   documentation.

By completing this lab, I will be able to:

- Use a Markdown editor to **create and edit** `.md` files
- Apply Markdown syntax to produce **well-formatted documents**
- **Create and clone** GitHub repositories
- **Stage, commit, and push** files and changes to a remote repository
